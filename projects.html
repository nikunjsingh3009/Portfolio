Voice-Controlled Appliance Controller

Completed in December 2025

View on GitHub ↗

An IoT-based smart home automation system engineered to eliminate manual switching barriers. The device enables real-time control over high-voltage home appliances through natural voice commands via Google Assistant and Amazon Alexa, backed by an ultra-low latency MQTT message broker and ESP32 microcontroller architecture.

⚡ Sub-Second Latency

MQTT lightweight pub/sub architecture delivering sub-second response times across the globe.

🛡️ Hardware Isolation

Optocoupler isolation and relay snubbers protecting sensitive ESP32 logic from high-voltage spikes.

🗣️ Multi-Assistant Voice

Integrated with IFTTT webhooks and Google Assistant / Alexa skills for natural language trigger parsing.

Detailed Engineering Contributions:

  • Microcontroller Programming: Programmed ESP32 using Arduino Framework & Embedded C with non-blocking event loops, relay switching, and real-time event handling.
  • Cloud & Messaging Integration: Configured MQTT and IFTTT for low-latency communication between voice assistants and connected appliances.
  • Hardware Circuit Engineering: Designed and tested relay-based hardware circuits with power management, device isolation, and surge suppression.
  • State Monitoring & Telemetry: Implemented real-time feedback loops to verify appliance state transitions and maintain synchronization across mobile applications.
  • Performance Optimization: Achieved sub-second response time for reliable, high-uptime appliance switching.

Technologies & Tools:

ESP32 Arduino Framework MQTT Protocol IFTTT Google Assistant API Alexa Skills Wi-Fi (802.11 b/g/n) Embedded C Relay Modules

Engineered to handle front-desk operations, multi-tier room reservations, real-time availability tracking, dynamic customer record management, and database transaction integrity.

🗃️ Normalized MySQL Schema

Relational tables eliminating redundant data and guaranteeing consistency across customer & booking entities.

⚡ Real-time CRUD Engine

🔒 Transaction Integrity

ACID compliant transaction execution preventing conflicting double-booking during concurrent check-ins.

Detailed Engineering Contributions:
